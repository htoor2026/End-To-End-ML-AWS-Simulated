MODEL LIFECYCLE

Safe retraining and promotion

  1. Log predictions and request IDs
  2. Attach actual sale prices when available
  3. Measure drift and model performance
  4. Require at least 30 labelled samples
  5. Train an MLflow candidate only when performance degrades
  6. Compare champion and candidate
  7. Promote or reject using quality gates
  8. Rollback to the previous champion if needed

PROMOTION GATES

Candidate quality requirements

≥ 1% MAE improvement
≤ 2% RMSE degradation
≤ 0.005 R² drop
